---
description: Wrap up a milestone
---
1. Run `pytest -q` and `ruff check .`.
2. Tick the milestone in `docs/PROGRESS.md` with date and test count.
3. Append any new decision to `docs/DECISIONS.md`.
4. `git add -A && git commit -m "M<nn>: <summary>"`.
5. Summarise what changed and what the next milestone needs.
